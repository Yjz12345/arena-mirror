### 🎮 游戏简介

一款 2D 俯视角竞技场战斗游戏。操控角斗士，逐层挑战越来越强的敌人，目标是通过全部 **100 层**。

**核心创意**：每次战败后，你的角色——包括属性、武器、学到的所有技能——会被游戏"记住"，变成下一层的敌人。越深入，遇到的敌人越像"曾经的你自己"。

```
"你的敌人终将全是你"
```

---

### 🔄 游戏循环

```
  主菜单
    ↓
┌→ 休息区（查看下一层敌人信息）─────────────┐
│    ↓ 按 Enter 进入战斗                    │
│  战斗（WASD 移动 + 鼠标瞄准 + 技能）        │
│    ↓ 胜利                                 │
│  选择奖励（回血/属性/技能升级/抽新技能）      │
│    ↓                                      │
└── 进入下一层 ──────────────────────────────┘
     ↓ 战败
  游戏结束 → 你的角色变成下层的前世敌人
```

```

│   ├── RewardSystem       战后 5 选 1 奖励
│   └── MetaProgression    局外成长（初始属性/复活/重roll）
├── traps/                 ← 陷阱系统（锯片/地刺/火焰/陷坑）
├── rendering/             ← 渲染层
│   ├── GameRenderer       画面绘制（7 种状态 + 全部 VFX + HUD + UI）
│   └── Vec2               二维向量工具类
└── data/                  ← 数据层（20+ 枚举 & 数据类）
```

### ⚔️ 战斗系统

| 按键 | 功能 |
|------|------|
| WASD | 移动 |
| 鼠标移动 | 瞄准 |
| 左键 | 普通攻击（扇形斩击，3 连击递增伤害） |
| 右键 | 武器特攻（重斩/剑刃回旋/蓄力突刺/冲锋/地震/连斩） |
| Q | 角色大招（战吼/旋风/无敌/嗜血/雷暴） |
| E | 通用技能（火球/冰箭/毒雾/震荡波/闪电链/治疗/激光等 11 种） |
| 空格 | 冲刺（无敌帧，可附带火径/护盾效果） |
| ESC | 暂停 |

**伤害类型**：普攻物理 + 附魔元素（火焰灼烧/冰冻减速/雷电连锁）+ 弹射物 + 持续伤害（燃烧 DOT、中毒 DOT）+ 范围伤害（旋风 AoE、雷暴雷击）

### 👻 前世 Sink 机制

游戏最独特的设计：

1. 玩家战败后，当前角色的**完整数据被打包**
2. 这个"前世幽灵"被插入战败层的下一层
3. 原来的敌人全部下移一格
4. 下次经过那一层，遇到的敌人就是"上次的自己"

前世敌人继承玩家所有技能和被动加成，技能 CD 缩短 85%。**你越强，未来的自己就越难打。**

### 📈 进度与成长

**局内成长（每层战后 5 选 1）**：回血 / 升级属性 / 升级技能 / 抽取新技能 / 随机事件

**局外成长（跨 Run 永久升级）**：初始生命 / 初始攻击 / 战后回血 / 重roll次数 / 复活机会

### ⚙️ 技术亮点

- 纯 JDK，无 Maven/Gradle、无第三方库，`javac` 直接编译
- 60FPS 游戏循环，基于 `javax.swing.Timer`
- 自建 `Vec2` 2D 向量数学库
- 数据驱动的技能池，按稀有度加权随机抽取
- 模组化状态机，7 种 GameState 通过事件监听器解耦
